Produces a sortable list of weapons in Splatoon 3.

Parameters

title Unnamed, optional. The text that will appear above the list. If absent, a default list title will be used.
collapsed Optional. Determines whether the collapsible region of the list is collapsed by default. Must be "true" or "false". If absent, the list will not be collapsible.
sub Optional. If present, only weapons with the given sub weapon will be included in the output.
special Optional. If present, only weapons with the given special weapon will be included in the output.
class Optional. If present, only weapons with the given class will be included in the output.
